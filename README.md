# آرشیو هوشمند حساب‌های X (توییتر)

برای آرشیو پست‌های قابل مشاهده در **وب عمومی X**، فقط نام یا آدرس پروفایل را وارد کنید. برنامه روی دستگاهی که سرور اجرا می‌شود، صفحه را در یک مرورگر Chromium تازه و بدون ورود باز می‌کند. نیازی به حساب X، توکن یا حساب توسعه‌دهنده نیست.

## امکانات

- افزودن حساب با `@username`، نام کاربری، لینک `x.com` یا `twitter.com` و لینک مستقیم پست
- ویرایش عنوان، فعال/غیرفعال کردن، حذف حساب و تنظیم مستقل بازه بررسی (دقیقه/ساعت/روز)
- دریافت دستی هر حساب یا همه حساب‌های فعال؛ بررسی زمان‌بند هر ۳۰ ثانیه، تا زمانی که برنامه باز است
- اولین دریافت: حداکثر ۱۰ پست از پست‌های نمایان در صفحه (قابل تنظیم از ۱ تا ۱۰۰)
- دریافت‌های بعدی: بررسی پست‌های نمایان با اسکرول محدود و ذخیرهٔ شناسه‌های جدیدتر پس از موفقیت بررسی
- جلوگیری از تکرار با نشانگر آخرین شناسه، قفل هر حساب و قید یکتایی SQLite
- ذخیره متن، لینک مستقیم، شناسه پست، تاریخ شمسی/میلادی، ساعت، نوع رسانه، لینک رسانه و بازدید در صورت نمایش در صفحه
- آرشیو صفحه‌بندی‌شده، جست‌وجو، فیلتر حساب/تاریخ/نوع محتوا و جزئیات پست
- خروجی Excel راست‌به‌چپ با دو شیت و محافظت از تزریق فرمول؛ شناسه‌های X به‌صورت متن برای جلوگیری از گرد شدن Excel
- خروجی SQLite مستقل (همه مطالب یا نتایج فیلترشده)، بدون اطلاعات ورود پروکسی
- حذف انتخابی/فیلترشده، پیش‌نمایش تعداد، پاک‌سازی کلی و امکان ریست نشانگر دریافت
- گزارش دریافت‌های دستی و خودکار، نمایش خطاهای دسترسی و محدودیت تعداد درخواست‌ها
- پشتیبان JSON از فهرست حساب‌ها و تنظیمات، بررسی فایل و بازیابی ادغام/جایگزینی؛ اطلاعات حساس به‌صورت پیش‌فرض حذف می‌شود
- منطقه زمانی قابل تنظیم (پیش‌فرض `Asia/Tehran`)، پروکسی اختیاری HTTP یا SOCKS5 بدون رمز
- دادهٔ نمونهٔ آزمایشی برای استفاده بدون اینترنت؛ رابط بدون CDN و بدون نیاز به سرور دیتابیس جداگانه

## چه چیزی قابل دریافت است؟

برای بررسی دسترسی، `https://x.com/username` را در یک پنجرهٔ خصوصی مرورگر، **بدون ورود** باز کنید. برنامه نیز با Playwright همین صفحه را باز می‌کند، منتظر نمایش پست‌ها می‌ماند و متن، زمان و پیوند پست را از خود صفحه می‌خواند. لینک مستقیم یک پست هنگام افزودن حساب به پروفایل نویسنده تبدیل می‌شود. برنامه از پروفایل یا کوکی‌های مرورگر شخصی شما استفاده نمی‌کند و پس از هر بررسی مرورگر دریافت را می‌بندد.

- اگر X صفحهٔ ورود نشان دهد، حساب محافظت شده باشد، درخواست‌ها را محدود کند یا صفحه قابل خواندن نباشد، نتیجه **خطا** است؛ این وضعیت به معنای «حساب بدون پست» نیست. برنامه تلاشی برای عبور از این محدودیت‌ها نمی‌کند.
- X ممکن است به مهمان تنها بخشی از پست‌ها را نشان دهد یا آن‌ها را به ترتیب زمانی نچیند. آرشیو کامل تاریخچه یا حتی نمایش تازه‌ترین پست تضمین نمی‌شود. دریافت اول از میان پست‌های مشاهده‌شده، بزرگ‌ترین شناسه‌ها را تا سقف انتخاب‌شده ذخیره می‌کند. بازنشر با شناسهٔ نویسندهٔ دیگر و محتوای داخل نقل‌قول به نام حساب ثبت نمی‌شوند.
- در بررسی بعد، برنامه به دنبال آخرین شناسهٔ ثبت‌شده می‌گردد. یک پست قدیمی یا سنجاق‌شده به‌تنهایی پایان بررسی نیست. اگر پست جدید دیده شود اما مرورگر به نشانگر قبلی نرسد، یا بارگذاری ناقص بماند، آن دریافت ذخیره نمی‌شود. اگر نشانگر مثلاً به دلیل حذف پست دیگر در صفحه نیست، می‌توانید از مدیریت حساب‌ها آن را **بدون حذف آرشیو** ریست کنید؛ دریافت بعدی دوباره از پنجرهٔ اولیه شروع می‌شود.
- متن همان بخش نمایش‌داده‌شده است؛ متن پنهان یا کاملِ پست‌های کوتاه‌شده بازیابی نمی‌شود. فقط لینک یک رسانه یا پیش‌نمایش آن ثبت می‌شود، نه فایل رسانه. بازدید فقط در صورت نمایش عدد دقیق ذخیره می‌شود. پست‌های بایگانی‌شده برای تغییر متن یا حذف از X بازخوانی نمی‌شوند.

## نصب و اجرا

Python **3.10 یا بالاتر** لازم است (پیشنهاد: 3.11).

### ویندوز

روی `start_windows.bat` دوبار کلیک کنید؛ محیط مجازی ساخته می‌شود، وابستگی‌ها و Chromium نصب می‌شوند و پنل در مرورگر شما باز می‌شود. برای توقف نسخه‌های در حال اجرا می‌توانید `stop_windows.bat` را اجرا کنید.

### لینوکس / مک

```bash
bash start_linux_mac.sh
```

### نصب دستی

```bash
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate
python -m pip install -r requirements.txt
python -m playwright install --only-shell chromium
python run.py
```

راه‌اندازهای ویندوز و لینوکس/مک نصب Chromium را بررسی می‌کنند. نصب اولیه به اینترنت نیاز دارد. در لینوکس اگر کتابخانه‌های سیستم موجود نیستند، `python -m playwright install-deps chromium` را با مجوز نصب بسته‌های سیستم اجرا کنید. برای مرور آرشیو و دادهٔ نمونه نیازی به نصب خود Chromium نیست.

پنل به‌طور پیش‌فرض روی `http://localhost:8000` اجرا می‌شود. اگر پورت اشغال باشد، برنامه پورت آزاد دیگری انتخاب می‌کند و آدرس نهایی را در کنسول چاپ کرده و در مرورگر باز می‌کند.

```bash
python run.py --port 9000
python run.py --host 127.0.0.1     # فقط همین کامپیوتر، پیشنهاد برای استفاده شخصی
python run.py --strict-port       # توقف به‌جای انتخاب پورت آزاد بعدی
```

### شروع استفاده

1. برای آزمایش بدون اینترنت، در «تنظیمات» روی «افزودن داده‌های نمونه آزمایشی» بزنید.
2. برای دریافت واقعی لازم نیست چیزی در تنظیمات وارد کنید. فقط اگر شبکهٔ شما به پروکسی نیاز دارد، آن را تنظیم کنید (نام کاربری و رمز پروکسی فقط برای HTTP پشتیبانی می‌شود).
3. در مدیریت حساب‌ها نام کاربری، بازه بررسی و تعداد دریافت اول را وارد کنید.
4. آرشیو و گزارش‌ها را بررسی کنید؛ خروجی‌های فیلترشده از زبانه آرشیو قابل دانلودند.
5. تاریخ فیلتر می‌تواند شمسی مثل `1405/08/26` یا میلادی مثل `2026-11-17` باشد.

زمان‌بند نیازمند باز ماندن برنامه است؛ فقط یک نمونه سرور با یک worker برای یک دیتابیس اجرا کنید. بازهٔ بررسی را متناسب با نیاز تنظیم کنید. اگر X خطای 429 نشان داد، بررسی را متوقف کنید و بعداً با فاصلهٔ بیشتری ادامه دهید.

## امنیت و پشتیبان‌گیری

این پنل **احراز هویت کاربری ندارد** و برای کامپیوتر شخصی/شبکه مورد اعتماد طراحی شده است. آن را مستقیم روی اینترنت منتشر نکنید؛ برای دسترسی راه دور، احراز هویت و HTTPS را در reverse proxy اضافه کنید. پیش‌فرض اجرا `0.0.0.0` است؛ برای محدود شدن به کامپیوتر خود `--host 127.0.0.1` بدهید.

نام کاربری و رمز پروکسی (در صورت تنظیم) در دیتابیس محلی به‌صورت رمزگذاری‌نشده نگهداری می‌شوند؛ از مجوزهای سیستم‌عامل و رمزگذاری دیسک استفاده کنید. فایل دیتابیس اصلی و `.env` در Git نادیده گرفته می‌شوند. خروجی SQLite اطلاعات حساس را حذف می‌کند. پشتیبان JSON پیش‌فرض نیز فاقد اسرار است، اما انتخاب صریح «کلیدهای حساس هم ذخیره شوند» آن‌ها را به فایل اضافه می‌کند؛ آن فایل را امن نگه دارید.

هنگام ارتقا، تنظیم توکن قدیمی از دیتابیس حذف می‌شود. حساب‌ها، مطالب، گزارش‌ها و آخرین شناسهٔ ثبت‌شده حفظ می‌شوند. بازیابی پشتیبان قدیمی توکن یا روش دریافت قبلی را برنمی‌گرداند؛ نسخه‌های قدیمی فایل‌های پشتیبان همچنان ممکن است توکن داشته باشند و باید امن نگه داشته شوند.

پشتیبان JSON شامل **مطالب آرشیو نیست**. برای نگهداری مطالب، خروجی SQLite بگیرید. خروجی SQLite یک فایل قابل بررسی در ابزارهای دیتابیس است؛ بازیابی آرشیو SQLite از پنل پیاده‌سازی نشده است. فرمت پشتیبان X مستقل از تلگرام است و فایل تلگرام برای بازیابی مستقیم پذیرفته نمی‌شود.

## Docker

```bash
docker compose up --build -d
docker compose logs -f
docker compose down
```

Chromium و وابستگی‌های سیستمی آن هنگام ساخت ایمیج نصب می‌شوند. داده‌ها در `./data` میزبان باقی می‌مانند. برای استفاده صرفاً محلی، نگاشت پورت compose را به `127.0.0.1:8000:8000` تغییر دهید. پروکسی از داخل پنل تنظیم می‌شود؛ `127.0.0.1` داخل کانتینر خود کانتینر است، نه میزبان.

## API محلی

مستندات تعاملی: `/docs`. برای سازگاری با ساختار مشترک پروژه مبنا، نام منابع در API و جداول همچنان `channels` است؛ در این پروژه منظور **حساب X** است.

| مسیر | کاربرد |
| --- | --- |
| `GET /api/overview` | آمار و وضعیت زمان‌بند |
| `GET/POST /api/channels` | فهرست/افزودن حساب |
| `PUT/DELETE /api/channels/{id}` | ویرایش/حذف حساب |
| `POST /api/channels/{id}/sync` | دریافت دستی |
| `GET /api/posts` | آرشیو با فیلتر و صفحه‌بندی |
| `POST /api/posts/bulk-delete` | حذف انتخابی یا فیلترشده |
| `GET /api/logs` | گزارش دریافت |
| `GET /api/exports/excel` | خروجی Excel |
| `GET /api/exports/sqlite` | خروجی SQLite |
| `GET/PUT /api/settings` | تنظیمات (اسرار در پاسخ بازگردانده نمی‌شوند) |
| `GET /api/backup/export` | پشتیبان JSON |
| `POST /api/backup/validate-file` | بررسی فایل |
| `POST /api/backup/restore-file` | بازیابی پشتیبان |
| `POST /api/demo/seed` | داده نمونه |
| `DELETE /api/demo` | حذف داده نمونه |
| `GET /healthz` | سلامت برنامه |

شناسه‌های بزرگ‌تر از محدوده امن عدد JavaScript در پاسخ JSON رشته هستند. در دیتابیس، شناسه پست به‌صورت عدد صحیح ۶۴ بیتی نگهداری می‌شود.

## تست

```bash
python -m pytest -q
node --check app/static/js/app.js
node --check app/collectors/timeline.js
```

تست‌ها به X وصل نمی‌شوند. علاوه بر آرشیو، خروجی‌ها و زمان‌بند، دریافت افزایشی، خطاهای دسترسی، حفظ نشانگر و مهاجرت تنظیمات قدیمی بررسی می‌شوند. تست مرورگر، یک پروفایل HTML محلی با پست‌های بارگذاری‌شونده هنگام اسکرول را رندر می‌کند؛ اگر Chromium نصب نباشد فقط آزمون مرورگر اجرا نمی‌شود (`skipped`).

## ساختار و مبنا

```text
app/
  api/routes.py             # API محلی
  collectors/x_web.py       # باز کردن پروفایل عمومی با Chromium
  collectors/timeline.js    # خواندن عناصر نمایش‌داده‌شدهٔ صفحه
  collectors/manager.py     # ضدتکرار و هماهنگی دریافت
  database.py               # SQLite، آرشیو، پشتیبان و گزارش
  services/                 # زمان‌بند و خروجی‌ها
  utils/                    # پارس حساب و تاریخ شمسی
  static/                   # CSS و JavaScript محلی
  templates/index.html      # پنل فارسی RTL
  responses.py              # حفظ دقت شناسه‌ها در مرورگر
tests/
```
