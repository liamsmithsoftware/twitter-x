# آرشیو هوشمند حساب‌های X (توییتر)

نسخه فارسی و راست‌به‌چپ سامانه آرشیو، با استفاده مجدد از ساختار پروژه `liamsmithsoftware/Telegram` و جایگزینی موتور دریافت با **API رسمی X v2**. این برنامه برای آرشیو و جست‌وجوی پست‌های حساب‌های عمومی است؛ ابزار انتشار پست یا مدیریت ورود کاربران X نیست.

## امکانات

- افزودن حساب با `@username`، نام کاربری، لینک `x.com` یا `twitter.com` و لینک مستقیم پست
- ویرایش عنوان، فعال/غیرفعال کردن، حذف حساب و تنظیم مستقل بازه بررسی (دقیقه/ساعت/روز)
- دریافت دستی هر حساب یا همه حساب‌های فعال؛ بررسی زمان‌بند هر ۳۰ ثانیه، تا زمانی که برنامه باز است
- اولین دریافت: پیش‌فرض فقط ۱۰ پست اخیر (قابل تنظیم ۱ تا ۱۰۰)
- دریافت‌های بعدی: `since_id` و صفحه‌بندی، ذخیره اتمیک پس از موفقیت همه صفحات
- جلوگیری از تکرار با نشانگر آخرین شناسه، قفل هر حساب و قید یکتایی SQLite
- ذخیره متن، لینک مستقیم، شناسه پست، تاریخ شمسی/میلادی، ساعت، نوع رسانه، لینک رسانه و بازدید در صورت ارائه API
- آرشیو صفحه‌بندی‌شده، جست‌وجو، فیلتر حساب/تاریخ/نوع محتوا و جزئیات پست
- خروجی Excel راست‌به‌چپ با دو شیت و محافظت از تزریق فرمول؛ شناسه‌های X به‌صورت متن برای جلوگیری از گرد شدن Excel
- خروجی SQLite مستقل (همه مطالب یا نتایج فیلترشده)، بدون توکن و رمز پروکسی
- حذف انتخابی/فیلترشده، پیش‌نمایش تعداد، پاک‌سازی کلی و امکان ریست نشانگر دریافت
- گزارش دریافت‌های دستی و خودکار، نمایش خطاهای دسترسی و محدودیت سهمیه
- پشتیبان JSON از فهرست حساب‌ها و تنظیمات، بررسی فایل و بازیابی ادغام/جایگزینی؛ اطلاعات حساس به‌صورت پیش‌فرض حذف می‌شود
- منطقه زمانی قابل تنظیم (پیش‌فرض `Asia/Tehran`)، پروکسی HTTP/SOCKS5
- داده نمونه صریحاً آزمایشی برای استفاده بدون API؛ رابط بدون CDN و بدون نیاز به سرور دیتابیس جداگانه

## تفاوت مهم با نسخه تلگرام

نسخه X از اسکرپ وب، کوکی مرورگر، ورود با شماره تلفن یا Telethon استفاده نمی‌کند. **دریافت واقعی نیازمند Bearer Token معتبر و دسترسی مناسب به endpointهای خواندن X API است.** هزینه، سهمیه و دسترسی به طرح حساب توسعه‌دهنده شما بستگی دارد. حساب‌های محافظت‌شده با این روش پشتیبانی نمی‌شوند.

برنامه از این مسیرها استفاده می‌کند:

```text
GET https://api.x.com/2/users/by/username/{username}
GET https://api.x.com/2/users/{id}/tweets
```

پس از ساخت دسترسی در پورتال توسعه‌دهندگان X، توکن را فقط در زبانه «تنظیمات» وارد و ذخیره کنید. توکن را در گفتگو، کد یا Git قرار ندهید. باقی ماندن `********` یعنی حفظ توکن؛ خالی کردن و ذخیره یعنی حذف آن. خطاهای 401، 403 و 429 در گزارش‌ها نمایش داده می‌شوند؛ برنامه محدودیت API را دور نمی‌زند.

**محدودیت‌ها:** آرشیو صرفاً تا جایی کامل است که API و طرح شما تاریخچه را ارائه کنند؛ بازیابی نامحدود همه پست‌های قدیمی تضمین نمی‌شود. در خطای یکی از صفحات، نشانگر جلو نمی‌رود و دریافت بعدی دوباره تلاش می‌کند. پست‌های قبلاً ذخیره‌شده برای تغییر متن، شمار بازدید یا حذف از X بازخوانی نمی‌شوند. بازدید ممکن است ارائه نشود و در آن صورت خالی می‌ماند. از میان رسانه‌های هر پست، اطلاعات اولین رسانه موجود ذخیره می‌شود؛ فایل‌های رسانه دانلود نمی‌شوند و لینک ویدیو می‌تواند تصویر پیش‌نمایش باشد. نظرسنجی فعلاً به شکل متن پست آرشیو می‌شود. زمان‌ها در هنگام دریافت با منطقه زمانی انتخاب‌شده ثبت می‌شوند.

## نصب و اجرا

Python **3.10 یا بالاتر** لازم است (پیشنهاد: 3.11).

### ویندوز

روی `start_windows.bat` دوبار کلیک کنید؛ محیط مجازی ساخته، وابستگی‌ها نصب و مرورگر باز می‌شود. برای توقف نسخه‌های در حال اجرا می‌توانید `stop_windows.bat` را اجرا کنید.

### لینوکس / مک

```bash
bash start_linux_mac.sh
```

### نصب دستی

```bash
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

پنل به‌طور پیش‌فرض روی `http://localhost:8000` اجرا می‌شود. اگر پورت اشغال باشد، برنامه پورت آزاد دیگری انتخاب می‌کند و آدرس نهایی را در کنسول چاپ کرده و در مرورگر باز می‌کند.

```bash
python run.py --port 9000
python run.py --host 127.0.0.1     # فقط همین کامپیوتر، پیشنهاد برای استفاده شخصی
python run.py --strict-port       # توقف به‌جای انتخاب پورت آزاد بعدی
```

### شروع استفاده

1. برای آزمایش بدون اینترنت، در «تنظیمات» روی «افزودن داده‌های نمونه آزمایشی» بزنید.
2. برای دریافت واقعی، Bearer Token را در تنظیمات وارد و ذخیره کنید؛ در صورت نیاز پروکسی را نیز تنظیم کنید.
3. در مدیریت حساب‌ها نام کاربری، بازه بررسی و تعداد دریافت اول را وارد کنید.
4. آرشیو و گزارش‌ها را بررسی کنید؛ خروجی‌های فیلترشده از زبانه آرشیو قابل دانلودند.
5. تاریخ فیلتر می‌تواند شمسی مثل `1405/08/26` یا میلادی مثل `2026-11-17` باشد.

زمان‌بند نیازمند باز ماندن برنامه است؛ فقط یک نمونه سرور با یک worker برای یک دیتابیس اجرا کنید. تنظیم کوتاه بازه ممکن است سهمیه API را مصرف کند. پس از 429 فاصله دریافت را افزایش دهید یا تا تجدید سهمیه صبر کنید.

## امنیت و پشتیبان‌گیری

این پنل **احراز هویت کاربری ندارد** و برای کامپیوتر شخصی/شبکه مورد اعتماد طراحی شده است. آن را مستقیم روی اینترنت منتشر نکنید؛ برای دسترسی راه دور، احراز هویت و HTTPS را در reverse proxy اضافه کنید. پیش‌فرض اجرا `0.0.0.0` است؛ برای محدود شدن به کامپیوتر خود `--host 127.0.0.1` بدهید.

توکن و رمز پروکسی در دیتابیس محلی به‌صورت رمزگذاری‌نشده نگهداری می‌شوند؛ از مجوزهای سیستم‌عامل و رمزگذاری دیسک استفاده کنید. فایل دیتابیس اصلی و `.env` در Git نادیده گرفته می‌شوند. خروجی SQLite اطلاعات حساس را حذف می‌کند. پشتیبان JSON پیش‌فرض نیز فاقد اسرار است، اما انتخاب صریح «کلیدهای حساس هم ذخیره شوند» آن‌ها را به فایل اضافه می‌کند؛ آن فایل را امن نگه دارید.

پشتیبان JSON شامل **مطالب آرشیو نیست**. برای نگهداری مطالب، خروجی SQLite بگیرید. خروجی SQLite یک فایل قابل بررسی در ابزارهای دیتابیس است؛ بازیابی آرشیو SQLite از پنل پیاده‌سازی نشده است. فرمت پشتیبان X مستقل از تلگرام است و فایل تلگرام برای بازیابی مستقیم پذیرفته نمی‌شود.

## Docker

```bash
docker compose up --build -d
docker compose logs -f
docker compose down
```

داده‌ها در `./data` میزبان باقی می‌مانند. برای استفاده صرفاً محلی، نگاشت پورت compose را به `127.0.0.1:8000:8000` تغییر دهید. پروکسی از داخل پنل تنظیم می‌شود؛ `127.0.0.1` داخل کانتینر خود کانتینر است، نه میزبان.

## API محلی

مستندات تعاملی: `/docs`. برای سازگاری با ساختار مشترک پروژه مبنا، نام منابع در API و جداول همچنان `channels` است؛ در این پروژه منظور **حساب X** است.

| مسیر | کاربرد |
| --- | --- |
| `GET /api/overview` | آمار و وضعیت زمان‌بند |
| `GET/POST /api/channels` | فهرست/افزودن حساب |
| `PUT/DELETE /api/channels/{id}` | ویرایش/حذف حساب |
| `POST /api/channels/{id}/sync` | دریافت دستی |
| `GET /api/posts` | آرشیو با فیلتر و صفحه‌بندی |
| `POST /api/posts/bulk-delete` | حذف انتخابی یا فیلترشده |
| `GET /api/logs` | گزارش دریافت |
| `GET /api/exports/excel` | خروجی Excel |
| `GET /api/exports/sqlite` | خروجی SQLite |
| `GET/PUT /api/settings` | تنظیمات (اسرار در پاسخ بازگردانده نمی‌شوند) |
| `GET /api/backup/export` | پشتیبان JSON |
| `POST /api/backup/validate-file` | بررسی فایل |
| `POST /api/backup/restore-file` | بازیابی پشتیبان |
| `POST /api/demo/seed` | داده نمونه |
| `DELETE /api/demo` | حذف داده نمونه |
| `GET /healthz` | سلامت برنامه |

شناسه‌های بزرگ‌تر از محدوده امن عدد JavaScript در پاسخ JSON رشته هستند. در دیتابیس، شناسه پست به‌صورت عدد صحیح ۶۴ بیتی نگهداری می‌شود.

## تست

```bash
python -m pytest -q
node --check app/static/js/app.js
```

۱۲۶ تست آفلاین: آرشیو، ضدتکرار، زمان‌بند، فیلتر، تاریخ، Excel، SQLite، پاک‌سازی، پشتیبان‌گیری و موتور X با `httpx.MockTransport`، از جمله صفحه‌بندی، عدم تغییر نشانگر پس از خطای صفحه بعد، خطاهای دسترسی/سهمیه و حفظ دقیق شناسه‌های طولانی. دریافت زنده از X بدون توکن و دسترسی شبکه آزمایش نشده است.

## ساختار و مبنا

```text
app/
  api/routes.py             # API محلی
  collectors/x_api.py       # دریافت از X API v2
  collectors/manager.py     # ضدتکرار و هماهنگی دریافت
  database.py               # SQLite، آرشیو، پشتیبان و گزارش
  services/                 # زمان‌بند و خروجی‌ها
  utils/                    # پارس حساب و تاریخ شمسی
  static/                   # CSS و JavaScript محلی
  templates/index.html      # پنل فارسی RTL
  responses.py              # حفظ دقت شناسه‌ها در مرورگر
tests/
```
